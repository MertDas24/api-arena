API Arena

Uygulaman API hatalarına gerçekten nasıl tepki veriyor? 1 dakikalık demo (sessiz, Türkçe arayüz).

  • Basit istemci ilk 503'te vazgeçiyor → rapor kontrolleri "Failed" gösteriyor.
  • Düzeltilmiş istemci aynı Idempotency-Key ve artan beklemeyle yeniden deniyor: 503 → 503 → 200.
  • Rapor her kontrol için beklenen / gözlenen / kanıt gösteriyor; önce/sonra karşılaştırması farkı ortaya koyuyor.
